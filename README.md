# etern8-watch

Внешний дозор ETERN8: раз в 5 минут проверяет сайты и серверы с GitHub и со второй точки (Vercel, проект etern8-tg-relay, /api/probe).
Адрес считается упавшим, только если не отвечает с обеих точек 2 проверки подряд. В Telegram пишет только при смене состояния.

Список адресов, ключ бота и чат - в секретах репозитория (TARGETS, TG_TOKEN, TG_CHAT, PROBE_URL, PROBE_KEY), в коде их нет.
TARGETS: JSON `[{"name": "...", "url": "https://...", "any": true}]`; `any` - любой HTTP-ответ считается живым (для адресов серверов по IP).
